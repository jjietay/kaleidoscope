# Gallery: storyboard

A catalogue, not a teaching video, in two parts.

- **Newsreel** (1 scene): a sample part of the newsreel style. The end still is `png/newsreel.png`.
- **Library catalogue** (8 scenes): one scene per library module, every item drawn still with its function name under it, on the style's own background. The end still of each scene is `png/library-<module>.png`.

- library scenes: none, the drawings only.
